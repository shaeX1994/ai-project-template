# 生产访问策略

本文件是 `visibility: restricted`。`ai-sync` 绝不把它的正文嵌入任何生成的入口文件,生成物里只留一个指针。
只有人为某个范围内的任务打开它时,agent 才会读到,这样生产细节不会进入每个模型的默认上下文。

采用模板时用你的真实规则替换下面的内容。

## 不可协商

- 任何 agent 都不对生产环境执行变更。Agent 产出变更和方案,由人执行。
- 生产凭据绝不进入 agent 的上下文,连"确认格式"也不行。任务看起来需要凭据时,停下交接。
- 影响线上资源的 IaC 变更,必须附 plan 或 dry-run 输出,并有具名的人工审批。

## 影响面

以下操作每一次都需要人明确确认才能执行:

- 删除或清空数据存储、存储桶、数据表;
- 批量更新、递归删除、大规模权限变更;
- 轮换或吊销正在使用的凭据;
- 修改线上服务的认证、授权或网络暴露面。

## 交接格式

工作停在这个边界时,输出:要执行什么、在哪个环境、确切命令、验证步骤、回滚方案。不执行任何一条。
